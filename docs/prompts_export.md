### 阶段 1：v0.2 校园基础地形 + 路网

```
任务：基于卫星图，搭建校园的基础地坪和路网

【实现要求】
1. 创建 createGround() 函数：主体地坪 200m×200m PlaneGeometry，浅灰绿色（0x9ab089）
2. 创建 createRoads() 函数：沿关键点生成连续道路面，沥青深灰（0x4a4a4a），Y=0.02
3. 道路宽度：主干道 6m，支路 3m
4. 加入 layerGroups.roads，receiveShadow = true
5. 操场南北走向，操场左边有主席台看台区域

【约束】
- 不要破坏 UI / Raycaster / 小地图代码
- 道路要 receiveShadow，地坪也要 receiveShadow
- OrbitControls maxDistance = 300
- 相机初始位置 (80, 60, 80)
```

### 阶段 2：v0.3 校园建筑

```
任务：基于 CAMPUS_DATA.md 中已校准的建筑坐标，添加 ~44 栋校园建筑

【重要约束】
- 所有建筑坐标以 CAMPUS_DATA.md 的 campusBuildings 数组为唯一数据源
- 绝对不要修改或重新估算建筑的 x、z 坐标

【实现要求】
1. createBuilding(info) 函数，根据 shape 生成不同形状（rect/L/U/longstrip）
2. 建筑外观：浅米色墙体、深灰屋顶、深蓝色窗户
3. 按 priority 分三级建模（high 精细 / medium 普通 / low 简化）
4. 每栋建筑 Group + userData + interactables + layerGroups.buildings
5. 窗户仅第一批建筑，每栋 < 30 个
```

### 阶段 3：v0.4 植被 + 设施

```
任务：添加校园植被（树木）和设施（路灯、长椅）

【实现要求】
- createTree(x, z, type)：树干 CylinderGeometry + 树冠球形/锥形
- createStreetLamp(x, z)：灯杆 + 灯头 SphereGeometry + PointLight（默认关，夜晚启用）
- createBench(x, z, rotY)：座板 + 支架
- 树木总数 60~100 棵，路灯 PointLight ≤ 25
- 全部加入 layerGroups.vegetation / layerGroups.facilities
```

### 阶段 4：v0.5 日夜循环

```
任务：让时间滑块真正控制日夜循环

【实现要求】
1. updateTimeOfDay(hour) 函数，hour 范围 0~24：
   - 太阳位置沿弧线运动（6:00 东方 → 12:00 正上方 → 18:00 西方）
   - 天空/雾颜色三段插值（白天蓝/晨昏橘红/深夜蓝）
   - 光照强度：白天 1.0/0.45，夜晚 0.1/0.15
   - 夜晚路灯 PointLight intensity = 0.5
2. time-slider input 事件接入 updateTimeOfDay
```

### 阶段 5：v0.6 校园漫游

```
任务：自动观光漫游 + 自由漫游

【自动观光】
- CatmullRomCurve3 环形路线，约 40 秒走一圈
- 相机抬到人眼高度 y+3，路过建筑自动弹卡片

【自由漫游】
- PointerLockControls + WASD + Shift 加速
- yaw/pitch 欧拉角，pitch 夹在 ±π/2
- 边界钳制，y 锁定 1.7m，不做碰撞不做跳跃
```

```
任务：提升展示效果的真实感

【4 项增强】

2. 建筑名称标签（js/labels.js）：CSS2DRenderer + glassmorphism 样式
3. 夜间泛光 + 窗户亮灯（js/bloom.js）：UnrealBloomPass + 窗户 emissive 切换
4. 粒子效果（js/effects.js）：白天落叶 + 夜间萤火虫
```

## 第三部分：关键技术决策摘要

| 决策 | 原因 |
|------|------|
| 椭圆形跑道而非体育场形 | 用户校园实际为椭圆环跑道 |
| 不做碰撞检测 | 开发时间有限，作业不要求 |
| PointerLockControls 自写 | 避免依赖 vendor 文件，更可控 |
| 路灯 PointLight ≤ 8 盏同时亮 | 防止夜间切换卡顿 |
| 云朵 18 朵 + 4 种贴图变体 | 提升视觉真实感但不影响性能 |
| Bloom 白天 strength=0 | 零性能开销，只在夜间生效 |
| location.js 硬编码而非 JSON | 双击 index.html 时 file:// 协议无法 fetch |
