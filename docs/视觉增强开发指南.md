# 校园数字孪生 — 视觉增强开发指南

## 项目背景

Three.js r128 校园数字孪生，**没有打包工具、没有 npm**，双击 `index.html` 直接跑。Three.js 是全局变量版本（`THREE.xxx`），不能用 `import`。

当前已完成：地面、道路、~40栋建筑、植被、路灯、日夜循环、编辑器、漫游模式。需要增强视觉效果用于展示。

## 重要提醒

- **`data/glb_cache.js`** 里面是 GLB 模型转成的 base64 字符串，几十MB，**千万不要用编辑器打开或者让 AI 读取**，会卡死。它是 `tools/build_glb_cache.py` 自动生成的，不需要手动编辑
- 所有 CDN 脚本必须匹配 **r128** 版本（`three@0.128.0`）
- 全局变量共享：`scene`, `camera`, `renderer`, `controls` 在 `core.js` 中声明，所有文件都能直接用
- 颜色常量在 `timeOfDay.js` 里已定义：`SKY_DAY=0x87ceeb`（白天蓝）、`SKY_DUSK=0xff8855`（晨昏橘）、`SKY_NIGHT=0x0a1530`（深夜蓝）

## 任务一：动态天空穹顶

**新建文件：`js/sky.js`**

### 思路

用一个巨大的球体（半径900）包住整个场景，内表面画渐变色当天空，比现在的纯色背景真实得多。

### 做法

1. 创建 `SphereGeometry(900, 32, 16)`，材质用 `ShaderMaterial`，设 `side: THREE.BackSide`（看内表面）
2. 设 `depthWrite: false`，`renderOrder: -1`，确保不遮挡任何物体
3. Shader 逻辑：
   - 顶点着色器：传递顶点世界坐标 Y 值（归一化到 0~1）
   - 片段着色器：根据 Y 值在 `底部色 → 地平线色 → 顶部色` 之间 `mix()` 插值
   - 可选：根据太阳方向加光晕热点（`dot(viewDir, sunDir)` 的幂次方）
4. 需要的 uniform：
   - `uTopColor`（vec3）— 天顶颜色，比天空色更深更饱和
   - `uHorizonColor`（vec3）— 地平线颜色，就是现有的天空色
   - `uSunPos`（vec3）— 太阳位置，从 `sun.position` 取
5. 加 5-8 个云朵：
   - 用 `THREE.Sprite` + canvas 画的白色径向渐变贴图（中间白色，边缘透明）
   - 放在 Y=150~250 高度，散布在不同 XZ 位置
   - 每帧沿 +X 方向缓慢移动（模拟风吹），超出范围循环回来
   - 夜间把 opacity 降到接近 0

### 需要改的地方

- **`js/timeOfDay.js`**：第 43 行 `scene.background = skyColor` 改成调用 `updateSkyDome(hour)` 更新 uniform 颜色。设 `scene.background = null`。雾色 `scene.fog.color` 保留不变
- **`js/main.js`**：`boot()` 里调用 `initSkyDome()`；`animate()` 里调用 `updateClouds(dt)` 让云飘动
- **`index.html`**：加 `<script src="./js/sky.js"></script>`，放在 `timeOfDay.js` 后面

## 任务二：窗户夜间亮灯

**改现有文件：`js/buildings.js` + `js/timeOfDay.js`**

### 思路

现有建筑已经有蓝色窗户贴片（PlaneGeometry），夜间把其中约 65% 随机切换成暖黄色发光材质。

### 做法

1. 在 `buildings.js` 顶部新增：

```js
const windowMeshes = [];  // 所有窗户 mesh 注册表
const windowMatOn = new THREE.MeshStandardMaterial({
  color: 0xffd080,
  emissive: 0xffa040,
  emissiveIntensity: 0.8,
  roughness: 0.3
});
// 原有的 windowMat（第161行）就是 "关灯" 状态，不用改
```

2. 修改 `addWindows()` 函数（第164行开始），每个 `win = new THREE.Mesh(...)` 创建后加：

```js
windowMeshes.push(win);
```

3. 在 `createBuildings()` 函数开头加 `windowMeshes.length = 0;`（编辑器重建场景时需要清空）

4. 在 `timeOfDay.js` 的 `updateTimeOfDay()` 末尾（路灯逻辑后面）加：

```js
// 窗户亮灯
var isNightWindow = (hour < 6 || hour > 18.5);
if (isNightWindow && !_windowsLit) {
  windowMeshes.forEach(function(win, i) {
    // 用索引做伪随机，同一帧内模式稳定
    win.material = ((i * 7 + 13) % 100 < 65) ? windowMatOn : windowMat;
  });
  _windowsLit = true;
} else if (!isNightWindow && _windowsLit) {
  windowMeshes.forEach(function(win) { win.material = windowMat; });
  _windowsLit = false;
}
```

在函数外面声明 `var _windowsLit = false;`

## 任务三：建筑名称标签

**新建文件：`js/labels.js`**

### 需要的 CDN

```html
<script src="https://cdn.jsdelivr.net/npm/three@0.128.0/examples/js/renderers/CSS2DRenderer.js"></script>
```

放在 `vendor/OrbitControls.js` 后面、业务脚本前面。

### 做法

1. 初始化 CSS2DRenderer：

```js
var labelRenderer;
var buildingLabels = [];
var labelsVisible = false;

function initBuildingLabels() {
  labelRenderer = new THREE.CSS2DRenderer();
  labelRenderer.setSize(window.innerWidth, window.innerHeight);
  labelRenderer.domElement.style.position = 'absolute';
  labelRenderer.domElement.style.top = '0';
  labelRenderer.domElement.style.left = '0';
  labelRenderer.domElement.style.pointerEvents = 'none';  // 关键！不拦截鼠标
  document.body.appendChild(labelRenderer.domElement);

  BUILDING_DATA.forEach(function(info) {
    var div = document.createElement('div');
    div.className = 'building-label';
    div.textContent = info.name;
    div.style.display = 'none';  // 默认隐藏

    var label = new THREE.CSS2DObject(div);
    label.position.set(info.x, info.h + 3, info.z);
    scene.add(label);
    buildingLabels.push({
      obj: label, div: div,
      pos: new THREE.Vector3(info.x, info.h + 3, info.z)
    });
  });
}

function toggleLabels(show) {
  labelsVisible = show;
  buildingLabels.forEach(function(item) {
    item.div.style.display = show ? '' : 'none';
  });
}

// 距离过滤，animate 里每帧调用
function updateLabels() {
  if (!labelsVisible) return;
  buildingLabels.forEach(function(item) {
    var dist = camera.position.distanceTo(item.pos);
    item.div.style.display = dist < 300 ? '' : 'none';
  });
}
```

2. CSS 样式加到 `styles/main.css`：

```css
.building-label {
  background: rgba(12, 22, 36, 0.75);
  backdrop-filter: blur(6px);
  border: 1px solid rgba(120, 200, 255, 0.25);
  border-radius: 6px;
  padding: 2px 8px;
  font-size: 11px;
  color: #cfe8ff;
  white-space: nowrap;
  font-family: 'Microsoft YaHei', sans-serif;
}
```

3. HTML：`index.html` 左侧面板的图层控制区下面加一行：

```html
<div class="row"><label for="toggle-labels">建筑标签</label>
  <input class="switch" type="checkbox" id="toggle-labels"></div>
```

4. 需要改的：
   - **`js/main.js`**：`boot()` 调 `initBuildingLabels()` 并绑定开关事件；`animate()` 里 render 后加 `if (labelRenderer) labelRenderer.render(scene, camera);` 和 `updateLabels();`
   - **`js/ui.js`**：`onResize()` 里加 `if (labelRenderer) labelRenderer.setSize(window.innerWidth, window.innerHeight);`

## 任务四：泛光 Bloom

**新建文件：`js/bloom.js`**

### 需要的 CDN（全部放在 vendor 后面，顺序不能乱）

```html
<script src="https://cdn.jsdelivr.net/npm/three@0.128.0/examples/js/shaders/CopyShader.js"></script>
<script src="https://cdn.jsdelivr.net/npm/three@0.128.0/examples/js/shaders/LuminosityHighPassShader.js"></script>
<script src="https://cdn.jsdelivr.net/npm/three@0.128.0/examples/js/postprocessing/ShaderPass.js"></script>
<script src="https://cdn.jsdelivr.net/npm/three@0.128.0/examples/js/postprocessing/EffectComposer.js"></script>
<script src="https://cdn.jsdelivr.net/npm/three@0.128.0/examples/js/postprocessing/RenderPass.js"></script>
<script src="https://cdn.jsdelivr.net/npm/three@0.128.0/examples/js/postprocessing/UnrealBloomPass.js"></script>
```

### 做法

```js
var composer, bloomPass;

function initBloom() {
  composer = new THREE.EffectComposer(renderer);
  composer.addPass(new THREE.RenderPass(scene, camera));

  bloomPass = new THREE.UnrealBloomPass(
    new THREE.Vector2(window.innerWidth, window.innerHeight),
    0.0,   // strength（白天=0）
    0.4,   // radius
    0.85   // threshold（只有亮度超过0.85的像素才泛光）
  );
  composer.addPass(bloomPass);
}
```

### 渲染管线改动（`js/main.js` 的 animate）

原来的 `renderer.render(scene, camera);` 改成：

```js
if (composer && bloomPass && bloomPass.strength > 0) {
  composer.render();
} else {
  renderer.render(scene, camera);
}
```

白天完全不走后处理，零性能损耗。

### Bloom 强度控制（加到 `js/timeOfDay.js` 的 updateTimeOfDay 末尾）

```js
if (typeof bloomPass !== 'undefined') {
  if (hour < 5 || hour > 20) {
    bloomPass.strength = 0.6;
  } else if (hour >= 5 && hour < 7) {
    bloomPass.strength = 0.6 * (1 - (hour - 5) / 2);
  } else if (hour > 18 && hour <= 20) {
    bloomPass.strength = 0.6 * ((hour - 18) / 2);
  } else {
    bloomPass.strength = 0.0;
  }
}
```

### Resize（`js/ui.js` 的 onResize 加）

```js
if (typeof composer !== 'undefined') composer.setSize(window.innerWidth, window.innerHeight);
```

### 已知坑

r128 的 EffectComposer 输出可能偏亮/发白。如果遇到，加一个 GammaCorrectionShader：

```html
<script src="https://cdn.jsdelivr.net/npm/three@0.128.0/examples/js/shaders/GammaCorrectionShader.js"></script>
```

在 `initBloom()` 最后加：

```js
composer.addPass(new THREE.ShaderPass(THREE.GammaCorrectionShader));
```

## 任务五：粒子效果

**新建文件：`js/effects.js`**

### 白天落叶

```js
var leafPoints, leafVelocities;

function initLeaves() {
  var count = 80;
  var positions = new Float32Array(count * 3);
  leafVelocities = [];

  for (var i = 0; i < count; i++) {
    positions[i * 3]     = (Math.random() - 0.5) * 400;
    positions[i * 3 + 1] = Math.random() * 50 + 10;
    positions[i * 3 + 2] = (Math.random() - 0.5) * 400;
    leafVelocities.push({
      vx: (Math.random() - 0.3) * 2,
      vy: -(Math.random() * 1.5 + 0.5),
      phase: Math.random() * Math.PI * 2
    });
  }

  var geo = new THREE.BufferGeometry();
  geo.setAttribute('position', new THREE.BufferAttribute(positions, 3));

  var mat = new THREE.PointsMaterial({
    size: 0.8, color: 0x8B6914,
    transparent: true, opacity: 0.7,
    sizeAttenuation: true, depthWrite: false
  });

  leafPoints = new THREE.Points(geo, mat);
  scene.add(leafPoints);
}

function updateLeaves(dt, hour) {
  if (!leafPoints) return;
  leafPoints.visible = (hour >= 6 && hour <= 19);
  if (!leafPoints.visible) return;

  var pos = leafPoints.geometry.attributes.position;
  for (var i = 0; i < pos.count; i++) {
    var v = leafVelocities[i];
    var x = pos.getX(i) + v.vx * dt;
    var y = pos.getY(i) + v.vy * dt;
    var z = pos.getZ(i) + Math.sin(performance.now() * 0.001 + v.phase) * 0.5 * dt;

    if (y < 0) {
      x = camera.position.x + (Math.random() - 0.5) * 200;
      y = 30 + Math.random() * 30;
      z = camera.position.z + (Math.random() - 0.5) * 200;
    }
    pos.setXYZ(i, x, y, z);
  }
  pos.needsUpdate = true;
}
```

### 夜间萤火虫

```js
var fireflyPoints, fireflyData;

function initFireflies() {
  var count = 60;
  var positions = new Float32Array(count * 3);
  var phases = new Float32Array(count);
  fireflyData = [];

  for (var i = 0; i < count; i++) {
    positions[i * 3]     = (Math.random() - 0.5) * 300;
    positions[i * 3 + 1] = 1 + Math.random() * 8;
    positions[i * 3 + 2] = (Math.random() - 0.5) * 300;
    phases[i] = Math.random() * Math.PI * 2;
    fireflyData.push({
      vx: (Math.random() - 0.5) * 1.5,
      vz: (Math.random() - 0.5) * 1.5,
      baseY: 1 + Math.random() * 8
    });
  }

  var geo = new THREE.BufferGeometry();
  geo.setAttribute('position', new THREE.BufferAttribute(positions, 3));
  geo.setAttribute('aPhase', new THREE.BufferAttribute(phases, 1));

  var mat = new THREE.ShaderMaterial({
    uniforms: { uTime: { value: 0 } },
    vertexShader: [
      'attribute float aPhase;',
      'uniform float uTime;',
      'varying float vAlpha;',
      'void main() {',
      '  vAlpha = clamp(sin(uTime * 2.0 + aPhase * 6.28), 0.0, 1.0);',
      '  vec4 mvPos = modelViewMatrix * vec4(position, 1.0);',
      '  gl_PointSize = 4.0 * (300.0 / -mvPos.z);',
      '  gl_Position = projectionMatrix * mvPos;',
      '}'
    ].join('\\n'),
    fragmentShader: [
      'varying float vAlpha;',
      'void main() {',
      '  float d = length(gl_PointCoord - 0.5) * 2.0;',
      '  if (d > 1.0) discard;',
      '  float glow = 1.0 - d;',
      '  gl_FragColor = vec4(1.0, 0.95, 0.5, glow * vAlpha * 0.8);',
      '}'
    ].join('\\n'),
    transparent: true, depthWrite: false, blending: THREE.AdditiveBlending
  });

  fireflyPoints = new THREE.Points(geo, mat);
  scene.add(fireflyPoints);
}

function updateFireflies(dt, hour) {
  if (!fireflyPoints) return;
  fireflyPoints.visible = (hour < 6 || hour > 19);
  if (!fireflyPoints.visible) return;

  fireflyPoints.material.uniforms.uTime.value += dt;

  var pos = fireflyPoints.geometry.attributes.position;
  for (var i = 0; i < pos.count; i++) {
    var fd = fireflyData[i];
    var x = pos.getX(i) + fd.vx * dt;
    var y = fd.baseY + Math.sin(performance.now() * 0.0005 + i) * 2;
    var z = pos.getZ(i) + fd.vz * dt;

    if (x > 200) x = -200;
    if (x < -200) x = 200;
    if (z > 200) z = -200;
    if (z < -200) z = 200;

    pos.setXYZ(i, x, y, z);
  }
  pos.needsUpdate = true;
}
```
