# 浙江树人学院数字孪生交互系统

> **本项目是浙江树人学院信息科技学院《计算机图形学》期中作业**

## 项目简介

基于 Three.js 构建的校园三维可视化系统，参考卫星图还原校园 ~44 栋建筑布局，提供透视/鸟瞰/漫游三种视角和点击查看建筑信息等交互功能。双击 `index.html` 即可运行，无需安装任何依赖。

## 技术栈

- HTML5 / CSS3 / JavaScript (ES6)
- Three.js r128（本地 vendor/ 目录，全局变量版）
- 腾讯混元3D（生成 GLB 地标模型）
- AI 辅助开发：Claude Code

## 功能介绍

### 三维场景

- **地坪**：1000m × 800m 浅灰绿草坪基底 + 校园边界框
- **路网**：16 条道路（ribbon mesh 连续条带），含黄色虚线中心线和白色边线
- **建筑**：~40 栋校园建筑（精细建模 / 普通体块 / 简化体块三级），坐标经人工校准
- **运动设施**：椭圆跑道（80m × 120m）、主席台看台、篮球场/网球场
- **植被**：~90 棵随机散布树木（阔叶/针叶），5 块绿化区域
- **设施**：25 盏路灯沿主要道路排列

### 交互功能

| 操作 | 效果 |
|---|---|
| 鼠标左键拖动 | 旋转视角 |
| 鼠标右键拖动 | 平移 |
| 滚轮 | 缩放 |
| 点击建筑/道路/设施 | 弹出信息卡（名称 + 类型 + 介绍） |
| 透视/鸟瞰/漫游按钮 | 切换三种视角模式 |
| 图层开关（6 个） | 独立显隐地面/道路/建筑/植被/设施/AI模型 |
| 时间滑块 | 切换时间显示（日夜效果待 v0.5） |
| 重置视角 | 恢复默认透视视角 |

## 运行方式

1. 克隆仓库
   ```bash
   git clone https://github.com/lysyminger/digital-twin-campus-threejs.git
   ```
2. 双击 `index.html` 用 Chrome / Edge 打开
3. 无需安装依赖，Three.js 已在 `vendor/` 目录中

## 坐标系约定

- 1 unit ≈ 1 米
- 校园中心 `(0, 0, 0)` = 贺田图书馆
- 东 = `+X`，西 = `-X`，北 = `-Z`，南 = `+Z`，上 = `+Y`
- 建筑坐标来源：`docs/CAMPUS_DATA.md`（人工拖拽校准，不可随意修改）
