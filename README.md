# 浙江树人学院数字孪生交互系统

> **浙江树人学院信息科技学院《计算机图形学》期中作业**

基于 Three.js 构建的校园三维可视化系统，参考卫星图还原拱宸桥校区 ~44 栋建筑布局。提供透视 / 鸟瞰 / 自动观光 / 第一人称自由漫游四种视角，可视化编辑器（草坪/建筑/道路），0~24 小时日夜循环（含夜间路灯）。**双击 `index.html` 即可运行**，无需安装任何依赖。

## 快速开始

### 方式一：双击打开（推荐）

```
双击 index.html → Chrome / Edge 自动打开
```

> **首次运行 / 新增 GLB 后必读**：双击 `tools/build_glb_cache.bat` 把 `assets/*.glb` 转为 `data/glb_cache.js` 缓存（`file://` 协议读不到本地 GLB，必须走 base64 缓存）。
> 如果新放进 `assets/` 的 GLB 没出现，多半是忘了重跑这个工具——控制台会有 `[AutoGLB] "xxx.glb" 不在 data/glb_cache.js 缓存中` 的提示。

### 方式二：HTTP 服务器（编辑调试用）

```bash
cd 项目根目录
python -m http.server 8080
# 浏览器打开 http://localhost:8080
```

HTTP 模式下 GLB 模型可直接从 `assets/` 加载，无需缓存。

## 三维场景

- **地坪**：1000m × 800m 浅灰绿草坪基底 + 校园边界框
- **路网**：23 条道路（ribbon mesh 连续条带），含黄色虚线中心线和白色边线，材质使用程序化沥青纹理
- **建筑**：~44 栋校园建筑（精细建模 / 普通体块 / 简化体块三级），坐标经人工校准
- **运动设施**：椭圆跑道（80m × 120m）、主席台看台、篮球场 / 网球场
- **植被**：自动散布树木（阔叶 / 针叶），9 块绿化区域 + 沿环路路边布点
- **设施**：路灯沿主要道路排列（夜间自动亮起），路边长椅

## 操作指南

### 基本操作

| 操作 | 效果 |
|------|------|
| 鼠标左键拖动 | 旋转视角 |
| 鼠标右键拖动 | 平移 |
| 滚轮 | 缩放 |
| 点击建筑 / 道路 / 设施 | 弹出信息卡（名称 + 类型 + 介绍） |
| 视角按钮（4 个） | 透视 / 鸟瞰 / 自动观光 / 自由漫游 |
| 图层开关（6 个） | 独立显隐 地面 / 道路 / 建筑 / 植被 / 设施 / AI 模型 |
| 时间滑块（0–24h） | 实时控制太阳位置、天空色、雾色、光照强度、夜间路灯 |
| 重置 | 退出所有漫游模式，恢复默认透视视角 |

### 视角模式

| 按钮 | 说明 |
|------|------|
| 透视 | 默认轨道相机，自由旋转 / 平移 / 缩放 |
| 鸟瞰 | 相机移至正上方 480m，俯视整个校园 |
| 观光 | 沿 18 个关键点构成的闭合环线巡游校园，约 40 秒一圈；路过建筑自动弹出信息卡 |
| 自由漫游 | WASD 移动 + 鼠标转头（PointerLock），Shift 加速，Esc 退出 |

### 日夜循环

- 太阳沿东 - 上 - 西半圆弧运动（hour=6/12/18 分别对应东方地平线 / 正上方 / 西方地平线）
- 天空 / 雾颜色按三段插值：白天蓝 ↔ 晨昏橘红 ↔ 深夜蓝
- 光照强度随时段切换（白天 1.0 / 晨昏 0.7 / 夜晚 0.1）
- 夜间（hour < 6 或 hour > 19）路灯自动点亮

### 可视化编辑器

| 快捷键 | 编辑器 | 功能 |
|--------|--------|------|
| **G** | 草坪编辑器 | 新增/删除/拖拽草坪，调整尺寸和颜色 |
| **B** | 建筑编辑器 | 新增/删除/拖拽建筑，调整参数，加载 GLB 模型 |
| **R** | 道路编辑器 | 新增/删除道路，拖拽路点，调整宽度 |

三个编辑器互斥，同时只能开一个。打开编辑器后左下角出现 **💾 下载存档** / **📂 导入存档** 按钮。

### 存档系统

1. 编辑完成后点 **💾 下载存档** → 浏览器下载 `location.js`
2. 将 `location.js` 放入项目 `data/` 目录（覆盖旧文件）
3. 刷新页面自动加载

### GLB 模型使用

1. 将 `.glb` 文件放入 `assets/` 目录
2. **双击打开**：运行 `tools/build_glb_cache.bat` 生成 base64 缓存 → 刷新页面
3. **HTTP 打开**：直接在建筑编辑器输入文件名加载，无需缓存
4. 在 `data/location.js` 中给建筑添加 `glb`/`glbScale`/`glbRotY` 字段可自动加载

## 技术栈

- **Three.js r128** — 三维渲染（本地 vendor，全局变量版，非 ES Module）
- **GLTFLoader** — GLB 模型加载（CDN: three@0.128.0）
- **腾讯混元3D** — 地标模型生成
- **Claude Code** — AI 辅助开发

## 坐标系约定

- 1 unit ≈ 1 米，校园总范围约 200m × 200m
- 校园中心 `(0, 0, 0)` = 贺田图书馆
- 东 = `+X`，北 = `-Z`，上 = `+Y`
- 建筑坐标来源：`docs/CAMPUS_DATA.md`
