# 浙江树人学院数字孪生交互系统

> **本项目是浙江树人学院信息科技学院《计算机图形学》期中作业**

## 项目简介

基于 Three.js 构建的校园三维可视化系统，参考卫星图还原校园 ~44 栋建筑布局。提供透视 / 鸟瞰 / 自动观光 / 第一人称自由漫游 四种视角，点击查看建筑信息，图层独立显隐，0~24 小时日夜循环（含夜间路灯）。双击 `index.html` 即可运行，无需安装任何依赖。

## 功能介绍

### 三维场景

- **地坪**：1000m × 800m 浅灰绿草坪基底 + 校园边界框
- **路网**：23 条道路（ribbon mesh 连续条带），含黄色虚线中心线和白色边线，材质使用程序化沥青纹理
- **建筑**：~44 栋校园建筑（精细建模 / 普通体块 / 简化体块三级），坐标经人工校准
- **运动设施**：椭圆跑道（80m × 120m）、主席台看台、篮球场 / 网球场
- **植被**：自动散布树木（阔叶 / 针叶），9 块绿化区域 + 沿环路路边布点
- **设施**：路灯沿主要道路排列（夜间自动亮起），路边长椅

### 交互功能

| 操作 | 效果 |
|---|---|
| 鼠标左键拖动 | 旋转视角 |
| 鼠标右键拖动 | 平移 |
| 滚轮 | 缩放 |
| 点击建筑 / 道路 / 设施 | 弹出信息卡（名称 + 类型 + 介绍） |
| 视角按钮（4 个） | 透视 / 鸟瞰 / 自动观光 / 自由漫游 |
| 图层开关（6 个） | 独立显隐 地面 / 道路 / 建筑 / 植被 / 设施 / AI 模型 |
| 时间滑块（0–24h） | 实时控制太阳位置、天空色、雾色、光照强度、夜间路灯 |
| 重置 | 退出所有漫游模式，恢复默认透视视角 |

#### 视角模式

- **透视**：默认轨道相机，自由旋转 / 平移 / 缩放
- **鸟瞰**：相机移至正上方 480m，俯视整个校园
- **自动观光**：相机沿 18 个关键点构成的 `CatmullRomCurve3` 闭合环线巡游校园（南门 → 西外路 → 北侧学院路 → 操场 → 中央 → 回南门），约 40 秒一圈；路过建筑（距离 < 15m）自动弹出信息卡 3 秒
- **自由漫游**：第一人称 WASD + 鼠标视角（PointerLock API）
  - `W A S D` 前后左右，`Shift` 加速（2.5×），鼠标转头，`Esc` 退出
  - 相机锁定人眼高度 1.7m，边界钳制在 X∈[-440,440] / Z∈[-310,310]
  - 屏幕中央准星 + 顶部按键提示条

#### 日夜循环

- 太阳沿东 - 上 - 西半圆弧运动（hour=6/12/18 分别对应东方地平线 / 正上方 / 西方地平线）
- 天空 / 雾颜色按三段插值：白天蓝 `#87ceeb` ↔ 晨昏橘红 `#ff8855` ↔ 深夜蓝 `#0a1530`
- 光照强度随时段切换（白天 1.0 / 晨昏 0.7 / 夜晚 0.1）
- 夜间（hour < 6 或 hour > 19）路灯 `PointLight` 与灯头 `emissive` 同步点亮

## 运行方式

1. 克隆仓库
   ```bash
   git clone https://github.com/lysyminger/digital-twin-campus-threejs.git
   ```
2. 双击 `index.html` 用 Chrome / Edge 打开
3. 无需安装依赖，Three.js 已在 `vendor/` 目录中

## 坐标系约定

- 1 unit ≈ 1 米
- 校园中心 `(0, 0, 0)` = 贺田图书馆
- 东 = `+X`，西 = `-X`，北 = `-Z`，南 = `+Z`，上 = `+Y`
- 建筑坐标来源：`docs/CAMPUS_DATA.md`（人工拖拽校准，不可随意修改）
